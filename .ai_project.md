# mlx-FireRedAudio

## Stack & Directory Structure
- Framework: Apple Silicon MLX + MLX-LM Metal kernels, NumPy/SoundFile I/O, Transformers preprocessing
- Entrypoint: `inference.py`, `scripts/benchmark.py`
- Core Package: `fireredaudio_mlx/`
- Models: `models/FireRedAudio-8bit/` (current local deployment; legacy norm corrections are applied at load time)
- Assets: `assets/examples/`
- Tests: `python -m unittest discover -s tests -v`
- Generation gate: `python scripts/test_generation_content_regression.py` (TTS + Voice Design content CER)
- Audit: `docs/MLX_NATIVE_AUDIT.md`
- Verified device: Apple M3 Max 128 GB, MLX 0.32.1, mlx-lm 0.31.3
